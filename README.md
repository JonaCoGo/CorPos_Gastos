# CorPos — Gestión de Gastos Familiares

App web/PWA y app Android (Capacitor) para la gestión financiera de una familia: salarios, gastos del hogar, personales, extras, mercado e historial por mes.

**Producción:** https://corpos-gastos.vercel.app/

## Desarrollo local

```bash
npm install
npm run dev
```

Requiere un `.env` con las variables de `.env.example`.

Qué es, cómo está hecho, comandos y el mapa de la documentación: [`CONTEXTO.md`](CONTEXTO.md).
